#002CHROME EXTENSIONIN USE

Magpie

An operational Chrome extension that saves support agents time on every add-on purchase: booking details go from the admin tool into vendor forms in one click.

ROLE
Design, build, roll out
YEAR
2026
STACK
Chrome Manifest V3 · JavaScript
STATUS
In daily use

01 · PROBLEM

Support agents buy add-ons for customers on many external vendor websites every day. Each purchase started the same way: copy a booking reference, a surname and passenger details out of the internal admin tool and retype them into a vendor form, field by field.

It is a few seconds each time, repeated all day by every agent. And a single wrong character fails the lookup and sends the agent back to the start.

02 · WHAT I BUILT

  • Capture without clicks. As an agent works through a purchase in the admin tool, the extension captures the booking on its own. Finishing a step captures the next one, so there is nothing extra to do.
  • Fill in one click. On the vendor site, the extension recognises the relevant fields and offers a fill chip, or a keyboard shortcut for the focused field. No retyping, no typos.
  • A short queue. Up to five recent passengers, newest first, each expiring after 30 minutes; the popup lets you promote or remove one.
  • Refuses to guess. If two passengers share the surname a booking is held under, the first name is left blank. A wrong first name fails a lookup as surely as a wrong surname.

04 · RESULTS

~2×add-on purchases per agent per day, from about 50 to about 97, with Magpie part of the push
1 clickto fill a vendor form, instead of a round of copy and paste and a retyped surname

In daily use by the support team since spring 2026, shipped in small releases driven by the team's feedback. A mistyped surname no longer sends an agent back to the start.

05 · WHAT I LEARNED

  • Count it in seconds per task. Agents repeat the same step all day, so a small saving on each one adds up to real time back.
  • Remove the click, not just the typing: capture has to happen as a side effect of work people already do.
  • When the data is ambiguous, leave the field blank. A tool that guesses wrong costs more time than one that stops.
