#003SLACK BOTLIVE

Orb

An operational Slack bot that gives support agents answers where they already work, so routine checks stop eating their time.

ROLE
Design, build, operate
YEAR
2026
STACK
Python · Slack API · Claude
STATUS
Live

01 · PROBLEM

Support agents lose time to the same small detours on case after case. Checking whether a customer's flight is still operating meant leaving the Slack thread, opening two systems and copying the result back. Handing a stuck case to the chat agent meant waiting for the one person who could run it.

None of it is hard. It just adds up, and every detour pulls an agent off the case in front of them.

02 · WHAT I BUILT

  • Lookups in the thread. @Orb flight status reads the case's flights, checks each one's live status and answers in the same thread. Read-only and open to every agent, so nobody switches tools for a routine check.
  • Hand-offs without the wait. @Orb hound drafts the brief for the chat agent, reviews it automatically and posts it for approval, so a stuck case moves on without queueing for one person. Nothing goes live until an authorised person presses Send.
  • Out of the way. One Slack message per case updates in place through drafting, review, live and ended, with Pause, Resume and Stop, so the thread stays readable for the agent working it.

04 · RESULTS

3+ minof manual steps and data entry per request, replaced by one message in the thread
0tools to switch and fields to type: the answer lands in the thread the agent is already in

Live for the support team since September 2026. Without Orb, every one of these requests meant at least three minutes of lookups and data entry, and an interruption that pulled the agent off the case in front of them. Handing a case to the chat agent no longer waits on one person either.

05 · WHAT I LEARNED

  • A tool for agents wins on time saved per case, not on features: the lookup has to be quicker than doing it by hand, or nobody uses it.
  • Separate read doors from write doors. Anyone can ask Orb a question; only named people can make it act.
  • Never send blind. Even a brief that already exists goes through review and a human press before an agent speaks.
